# 彩虹 · Supabase 配置说明

你现在停留在 Supabase 的 **Create a new project** 页面，按下面步骤完成即可。

---

## 1. 创建项目

按截图页面填写：

- **Project name**：建议填 `caihong`（或你喜欢的英文名，纯英文/数字）
- **Database password**：设置一个强密码（可点 Generate a password 随机生成），**请保存好**
- **Region**：选 `Asia-Pacific`（离你最近）
- 保持勾选：
  - ✅ Enable Data API
  - ✅ Automatically expose new tables
- 点击 **Create new project**，等待 1-3 分钟数据库就绪

---

## 2. 开启匿名登录

进入项目后：

1. 左侧菜单 → **Authentication**
2. 展开 **Providers**（或 **Sign In / Up**）
3. 找到 **Anonymous** 提供商，把它 **Enable**

彩虹使用 Supabase 匿名登录，每个设备自动获得一个临时用户，不需要邮箱/手机号。

---

## 3. 执行建表 SQL

1. 左侧菜单 → **SQL Editor**
2. 点 **New query**
3. 把 `sql/init.sql` 完整内容复制进去
4. 点 **Run**

如果运行成功，表、视图、RLS、Realtime、Storage 桶就全部建好了。

---

## 4. 填入前端配置

1. 左侧菜单 → **Project Settings**（齿轮图标）→ **API**
2. 复制两项：
   - **Project URL**（类似 `https://xxxxxxxxxxxxxxxx.supabase.co`）
   - **anon public**（一串 `eyJ...` 开头的 key）
3. 打开本项目的 `js/config.js`，替换双引号里的内容：

```js
export const SUPABASE_URL = 'https://你的项目ID.supabase.co';
export const SUPABASE_ANON_KEY = 'eyJ...你的anon key...';
```

保存后刷新浏览器页面，顶部黄色提示条就会消失，App 开始连接云端。

---

## 5. Storage 说明（可选检查）

SQL 已自动创建三个私有 bucket：

- `avatars`：头像
- `diary`：日记中的照片（照片墙唯一来源）
- `chat`：聊天图片

如果之后上传失败，可到 **Storage → Policies** 检查上面三个 bucket 是否已有「authenticated 可读写」策略。

---

## 6. 测试配对

两个设备分别打开彩虹：

- 设备 A：选择「创建我们的空间」→ 设置昵称/头像/代表色/起始日 → 获得 6 位配对码
- 设备 B：选择「加入 TA」→ 输入配对码 → 完成绑定

之后双方所有数据会自动通过 Supabase 实时同步。
